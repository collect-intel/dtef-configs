## Cursor Cloud specific instructions

This is a **data/configuration repository** (`collect-intel/dtef-configs`), not a runnable application. It stores YAML evaluation blueprints and JSON model collections consumed by the separate [dtef-app](https://github.com/collect-intel/dtef-app) repo.

### Services

There are no services to run in this repo. The only executable code is the CI validation script.

### Lint / Validate

Run the blueprint validation script (the repo's only CI check):

```bash
python3 .github/scripts/validate_blueprints.py <blueprint-files...>
```

Example — validate all blueprints in a directory:

```bash
python3 .github/scripts/validate_blueprints.py blueprints/gd1/*.yml
```

Requires Python 3.10+ and `pyyaml` (pre-installed in the VM via `pip install pyyaml`).

### Model collection files

The `models/*.json` files are plain JSON arrays of model ID strings. They are not validated by the CI script but can be checked with:

```bash
python3 -c "import json, sys; json.load(open(sys.argv[1])); print('OK')" models/CORE.json
```

### Key notes

- **Do not hand-edit blueprint YAML files.** They are machine-generated by the dtef-app CLI. See `README.md` and `.claude/CLAUDE.md` for the generation workflow.
- Blueprint `configId` values contain colons (e.g., `ageGroup:18-25`). File paths with colons need quoting in shell commands.
- Full validation of all 1,306 blueprints takes ~2–3 minutes.
